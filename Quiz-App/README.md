# Quiz App

A Flutter quiz application built while following **Maximilian Schwarzmüller's Flutter & Dart course**.

The project focuses on widgets, user interaction, state changes, and displaying dynamic content.

## About

The app presents a series of questions to the user.

Users can select answers, move through the quiz, and view a summary of their results after completing the questions.

## Features

* Multiple quiz questions
* Answer selection
* Randomized answer order
* Quiz navigation
* Result summary
* Restarting the quiz

## What I Learned

* Stateful widgets
* Managing application state
* Handling user interaction
* Passing data between widgets
* Lists and dynamic content
* Conditional UI rendering
* Building reusable widgets
* Working with Dart classes and objects
