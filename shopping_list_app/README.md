# Shopping List App

A Flutter shopping list application built while following **Maximilian Schwarzmüller's Flutter & Dart course**.

The project focuses on forms, user input, HTTP requests, and working with backend data.

## About

The application allows users to create and manage shopping items.

Each item can contain information such as its name, quantity, and category.

## Features

* Add shopping items
* Remove shopping items
* Display shopping items
* Specify item quantity
* Select item categories
* Form validation
* Communicate with a backend
* Load remote data
* Handle asynchronous operations
