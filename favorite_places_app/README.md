# Favorite Places

A Flutter application for saving and managing favorite locations, built while following **Maximilian Schwarzmüller's Flutter & Dart course**.

The project focuses on accessing native device features, handling images, maps, and storing application data.

## About

Users can create favorite places by adding information about a location, capturing an image, and storing its geographical position.

## Features

- Add favorite places
- Save place information
- Capture photos using the device camera
- Store geographical locations
- Display saved places
- Work with maps
- Persist application data

## Api Configration

1. Create your own Geopify account and project
2. Copy the api key in API Keys tab
3. Insert that to lib/models/place.dart on apikey const variable
