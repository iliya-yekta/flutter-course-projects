# Chat App

A Flutter chat application built while following **Maximilian Schwarzmüller's Flutter & Dart course**.

This project introduces backend services, authentication, real-time messaging.

## About

The application allows users to create an account, authenticate, and communicate through a chat interface.

It uses Firebase-based services to handle backend functionality.
Some of those services needed creadit card. So, in this project hasn't been added.

## Features

- User registration
- User authentication
- Login and logout
- Chat interface
- Send and receive messages
- Backend integration

## What I Learned

- Firebase integration
- User authentication
- Cloud backend services
- Database interaction
- Handling asynchronous operations
- Authentication state
- Backend-driven application architecture
- Managing remote application data

## Technologies

- Firebase (clould_firestore, firebase_messaging, firebase_auth)
