# Todo App

A simple Flutter Todo application built while following **Maximilian Schwarzmüller's Flutter & Dart course**.

## About

The application allows users to manage a list of tasks.

Users can mark tasks as completed or incomplete and organize the displayed tasks.

## Features

* Add and display tasks
* Mark tasks as completed
* Mark tasks as incomplete
* Sort tasks
* Display task status
* Interactive task management
